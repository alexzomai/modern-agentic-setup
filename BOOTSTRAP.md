# BOOTSTRAP.md

Одноразовая инструкция для AI-агента: развернуть окружение агентной разработки в новом проекте из этого шаблона. Выполняйте шаги по порядку из корня проекта. После успешной проверки удалите этот файл.

## 1. Спросите пользователя

- Название проекта и краткое описание.
- Стек (язык, фреймворк, менеджер пакетов).
- Язык артефактов OpenSpec (например, русский или английский).
- Какие агенты используются: Claude Code, Codex, OpenCode (по умолчанию все три).
- Нужна ли база данных Postgres. Если нет, удалите сервер `postgres` из `.mcp.json`, `opencode.json`, `.codex/config.toml`, упоминание о нём в разделе «MCP» в `AGENTS.md` и `.env.example`.
- Нужен ли UI. Если нет, пропустите шаг 5, удалите сервер `shadcn` из трёх конфигов MCP и упоминания UI-скилла и `shadcn` из `AGENTS.md`.
- Лицензия проекта: оставить MIT с именем пользователя, выбрать другую или убрать (для закрытого проекта).
- Куда пушить проект (URL нового репозитория), если `origin` всё ещё указывает на репозиторий шаблона (см. шаг 3).

## 2. Проверьте окружение

Нужны `node`/`npx`, `python3` (для скилла UI/UX), `uv`/`uvx` (для сервера `postgres`). Не устанавливайте их сами: если чего-то нет, сообщите пользователю.

## 3. Превратите шаблон в проект

Цель — чтобы в репозитории не осталось ничего про шаблон, только про проект.

- **`README.md`**: замените содержимое целиком, ничего из шаблона не оставляйте:

  ```markdown
  # <название проекта>

  <краткое описание в одно-два предложения>
  ```

- **`AGENTS.md`**: замените `<project-name>` на название проекта, заполните раздел «Команды» по выбранному стеку, удалите разделы и строки про то, что не используется (БД, UI, неиспользуемые агенты в таблице команд OpenSpec).
- **Неиспользуемые агенты**: удалите их конфиги — `opencode.json` (OpenCode), `.codex/` (Codex), `CLAUDE.md`, `.mcp.json` и `.claude/settings.json` (Claude Code) — и уберите их из `--tools` на шаге 4.
- **`LICENSE`**: по ответу пользователя впишите его имя и текущий год, замените на выбранную лицензию или удалите файл.
- **`.gitignore`**: добавьте записи для выбранного стека (артефакты сборки, кэши, зависимости), если их ещё нет.
- **`.env.example`**: если БД не используется, удалите файл. Если используется — скопируйте в `.env` и попросите пользователя заполнить `DATABASE_URI`. Не коммитьте `.env`.
- **Git**: проверьте `git remote get-url origin`. Если он указывает на репозиторий шаблона (`modern-agentic-setup`), смените его на репозиторий проекта (`git remote set-url origin <url>`). Если проект склонирован, а не создан через «Use this template», в истории останутся коммиты шаблона: предложите пользователю начать историю заново (`rm -rf .git && git init`). Это необратимо — делайте только после явного согласия.
- **Код проекта не создавайте**: bootstrap готовит только окружение агентов. Scaffolding стека и первые фичи — через `openspec-propose` после bootstrap.

## 4. Установите OpenSpec

Если CLI нет, попросите пользователя установить: `npm install -g @fission-ai/openspec`.

```
openspec init --tools claude,codex,opencode --profile core --no-animation
```

Оставьте в `--tools` только выбранных агентов. Не передавайте `--language`: `openspec/config.yaml` уже есть в шаблоне, и с этим флагом init завершится ошибкой. Появятся `.claude/commands/opsx/`, `.opencode/commands/` и скиллы `openspec-*`.

Язык артефактов добавьте в `openspec/config.yaml` вручную:

```yaml
context: |
  Write all artifacts in <язык>
```

OpenCode сам читает `.agents/skills/` и `.claude/skills/`, поэтому удалите его дубликат скиллов: `rm -rf .opencode/skills`. Команды в `.opencode/commands/` оставьте.

## 5. Установите скилл UI/UX (если нужен UI)

```
npx -y ui-ux-pro-max-cli@2.15.0 init --ai claude
```

Если классификатор прав блокирует команду, попросите пользователя запустить её в терминале (в сессии Claude Code: `! npx -y ui-ux-pro-max-cli@2.15.0 init --ai claude`).

## 6. Перенесите скиллы в `.agents/skills`

Установщики пишут в `.claude/skills/`. Скиллы должны жить в `.agents/skills/`, а `.claude/skills` быть симлинком на неё. Если `.claude/skills` уже симлинк, пропустите шаг.

```
mkdir -p .agents/skills
cp -R .claude/skills/. .agents/skills/
rm -rf .claude/skills
ln -s ../.agents/skills .claude/skills
```

Если в `.agents/skills` уже есть скилл с тем же именем, не перезаписывайте его молча: сначала сравните версии.

## 7. Подключите MCP

Попросите пользователя:

- **Claude Code:** перезапустить сессию, подтвердить серверы из `.mcp.json` и проверить их через `/mcp`.
- **Codex:** при первом запуске в проекте отметить его как доверенный (иначе `.codex/config.toml` не читается) и проверить `codex mcp list`.
- **OpenCode:** проверить `opencode mcp list`.
- **Postgres:** перед запуском агента экспортировать переменные из `.env` в shell (`set -a; source .env; set +a` или direnv). Агенты не читают `.env` сами.

## 8. Проверка

- [ ] В `AGENTS.md` нет `<project-name>` и плейсхолдеров `<команда>`.
- [ ] `README.md` содержит только название и описание проекта.
- [ ] `LICENSE` соответствует выбору пользователя (или удалён).
- [ ] `origin` не указывает на репозиторий шаблона.
- [ ] Остатков шаблона нет: `grep -rniE "шаблон|template|modern-agentic-setup|<project-name>|<команда>" --exclude-dir=.git --exclude-dir=.agents --exclude-dir=.claude --exclude-dir=.opencode --exclude-dir=node_modules .` ничего не находит, кроме `BOOTSTRAP.md` и строки про него в начале `AGENTS.md`.
- [ ] `openspec/config.yaml` существует и содержит язык артефактов.
- [ ] Скиллы лежат в `.agents/skills/`, `.claude/skills` — симлинк на неё, `.opencode/skills` нет.
- [ ] Для UI: есть `.agents/skills/ui-ux-pro-max/SKILL.md`.
- [ ] Наборы серверов в `.mcp.json`, `opencode.json` и `.codex/config.toml` совпадают.
- [ ] `.env` (если есть) не отслеживается git.

Когда все пункты выполнены, удалите `BOOTSTRAP.md` и строку про него в начале `AGENTS.md`, закоммитьте результат одним коммитом `chore: bootstrap project from template` (не пушьте) и сообщите пользователю, что осталось сделать вручную.
